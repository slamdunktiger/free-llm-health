## How it Works

1. **Hourly probe**: VPS bot pings each provider's `/models` endpoint
2. **SQLite storage**: Raw results stored with timestamps
3. **current.json**: Latest snapshot of all providers + models
4. **Daily report**: Markdown summary at 23:00 UTC
5. **GitHub push**: Auto-committed after each probe

## Usage

```bash

# Generate daily report
python3 probe.py --report

# Push current.json to GitHub
```
